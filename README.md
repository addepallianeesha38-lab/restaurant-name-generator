# Restaurant Name Generator

An app that creates a fancy restaurant name and menu items for any cuisine.

## Live App
https://restaurant-name-generator-edrl2dzzi8hlancqutrxvu.streamlit.app/

## How it works
- You pick a cuisine (Indian, Italian, Mexican, Arabic, American).
- The first chain makes a restaurant name.
- The second chain makes menu items for that name.

## Tools used
- Python
- LangChain
- Google Gemini API
- Streamlit

## Note
This is a demo that uses the free Gemini API. If the daily limit is finished, it may show an error until the next day.
